Privacy Policy

Effective: September 28, 2026

This Privacy Policy explains how Advertisement Cleaner accesses, uses, stores, and protects Google user data. Advertisement Cleaner is a personal automation operated by its developer for the developer’s own Gmail account.

Summary: Google user data is used only to organize promotional email and perform an owner-triggered cleanup. It is not sold, used for advertising, or shared with third parties.

Google data the application accesses

The application requests the Gmail permission https://www.googleapis.com/auth/gmail.modify. This permits it to list messages and labels and to modify message labels or move messages to Trash. It may process message identifiers, Gmail category and label assignments, and the minimum message metadata returned by Gmail for these actions.

How Google user data is used

  • Find messages categorized by Gmail as Promotions.
  • Apply the custom “Advertisement” label.
  • Remove labeled promotional messages from Inbox.
  • Move non-trashed messages carrying that label to Trash after the owner completes the configured Apple Reminder.

Google user data is not used to build advertising profiles, serve advertisements, train generalized artificial-intelligence models, determine creditworthiness, or for any unrelated purpose.

Storage and retention

The OAuth authorization token and automation state are stored locally on the owner’s Mac. The application does not maintain a remote database of Gmail messages or message content. Operational logs may record counts, status information, and errors locally; they are not intended to contain email bodies.

Local authorization and state files remain until the owner deletes them. Messages moved to Gmail Trash are retained and deleted according to Gmail’s own trash-retention behavior and the owner’s actions.

Sharing and transfer

Advertisement Cleaner does not sell Google user data. It does not share or transfer Google user data to third parties, except as necessary for Google’s Gmail API to provide the requested functionality, to comply with applicable law, or to protect against fraud, abuse, or security threats.

Security

OAuth credentials and tokens are excluded from source control and stored in local application-support files. Access is limited to the Mac user account running the automation. No method of storage is completely secure, but reasonable safeguards are used for this personal utility.

Your controls

The owner can stop the background automation, delete the local OAuth token, remove the application’s access from the Google Account security settings, or delete the Google Cloud OAuth client. Revoking access prevents further Gmail API activity until authorization is granted again.

Google API Services User Data Policy

Advertisement Cleaner’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this policy

This policy may be updated if the application’s behavior or legal requirements change. The effective date above will be revised when material updates are published.
