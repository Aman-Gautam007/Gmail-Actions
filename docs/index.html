Personal inbox housekeeping

Promotions organized. Cleanup on your signal.

Advertisement Cleaner is a private, locally run utility that organizes Gmail Promotions under an Advertisement label and moves them to Trash only after its owner completes a matching Apple Reminder.

1

Organize

Promotional messages receive the Advertisement label and are removed from Inbox.

2

Review

The owner can review the Advertisement label before cleanup.

3

Clean

Completing the designated reminder triggers the local cleanup.

Purpose

One focused job

The utility uses the Gmail API with permission to modify mail. It identifies messages already categorized by Gmail as Promotions, applies a dedicated label, archives those messages from Inbox, and moves labeled messages to Trash when the owner completes a specific reminder.

It is designed for the developer’s personal account. It does not provide advertising, analytics, user registration, or data-sharing services.

Local operation

The automation and its authorization token run and remain on the owner’s Mac.

Limited access

Gmail access is used only to label, archive, list, and trash the messages needed for this workflow.

No data sales

Google user data is not sold, shared for advertising, or transferred to data brokers.
